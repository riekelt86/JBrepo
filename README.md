# Jelbert Reisadvies

Een satirische reisadvies-website ("omdat thuisblijven ook maar zo saai is"), gemaakt in gewone HTML en CSS.

Open `index.html` in je browser, meer is niet nodig.

| Bestand | Inhoud |
| --- | --- |
| `index.html` | Home met slideshow van de "beste" bestemmingen |
| `about.html` | Over Jelbert en de reispakketten |
| `bestemmingen.html` | Alle bestemmingen (hierheen linken de READ MORE-knoppen) |
| `blog.html` | Blogposts |
| `contact.html` | Contactgegevens |
| `css/style.css` | Alle styling |
| `js/main.js` | Slideshow, mobiel menu en de zoekbalk |

**Nieuwe slide toevoegen:** kopieer een `<div class="slide">` blok in `index.html`, pas de tekst, de kleuren (`--sky1`, `--sky2`, ...) en de vlag-SVG aan. Liever een echte foto? Zet `style="background: url(img/foto.jpg) center/cover"` op de slide en haal de `scenery` en `flagpole` weg.
